## ✨ Features

- 🎯 **100+ Apps** - Popular software organized by category
- 📦 **Ninite-Style Layout** - All categories visible at once
- 🖼️ **Manual Icons** - High-quality icons from Wikimedia Commons
- 🔍 **Instant Search** - Filter apps by name or package ID
- 📋 **One-Click Copy** - Copy commands to clipboard instantly
- ⚙️ **Options** - Silent install, auto-accept agreements
- 🌙 **Dark Theme** - VS Code inspired design
- 📱 **Responsive** - Works on all devices
